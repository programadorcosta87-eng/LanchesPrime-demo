# LanchesPrime — Demonstração

Site demonstrativo de uma plataforma de lanchonete, com interface moderna, cardápio interativo e layout responsivo.

---

## 📋 Sobre o projeto

O **LanchesPrime** é uma versão demonstrativa criada para apresentar uma experiência visual de um site de lanchonete.

A página reúne uma apresentação institucional, navegação entre seções e um cardápio ilustrativo com produtos organizados por categorias. A interface foi desenvolvida para demonstrar como um estabelecimento pode apresentar seus produtos de forma clara, moderna e acessível.

Este repositório é independente do projeto privado LanchesPrime. Seu conteúdo foi preparado exclusivamente para demonstração e portfólio, sem incluir o código interno, as rotas, as APIs, as credenciais ou a infraestrutura do projeto privado.

---

## ✨ Funcionalidades

* Página inicial com apresentação do projeto
* Identidade visual moderna
* Cardápio demonstrativo com produtos ilustrativos
* Filtros por categoria
* Interações locais para demonstrar a experiência do cardápio
* Navegação entre as seções
* Layout responsivo para computadores, tablets e smartphones
* Interface adaptada para diferentes tamanhos de tela

---

## 🛠️ Tecnologias

* Next.js
* React
* TypeScript
* CSS3
* JavaScript
* Unsplash — imagens ilustrativas carregadas por URLs públicas

---

## 🎯 Objetivo do projeto

O objetivo deste projeto é apresentar uma demonstração visual de uma plataforma para lanchonetes, destacando a organização de um cardápio digital, a experiência de navegação e a construção de interfaces responsivas.

O projeto também demonstra conhecimentos relacionados ao desenvolvimento front-end, componentização, organização de páginas, estilização, interatividade e experiência do usuário.

---

## 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência adequada em:

* Computadores
* Tablets
* Smartphones

Os elementos da página são reorganizados conforme o tamanho da tela, mantendo a navegação e a visualização do cardápio acessíveis em dispositivos móveis.

---

## 🔒 Privacidade e segurança

* Este repositório contém somente a versão demonstrativa da interface.
* Não inclui conexão com o banco de dados do projeto privado.
* Não inclui APIs, rotas internas ou painel administrativo do projeto privado.
* Não contém credenciais, tokens, chaves ou arquivos de ambiente.
* Os produtos, descrições e preços exibidos são ilustrativos.
* As interações do cardápio acontecem localmente no navegador e não enviam nem armazenam pedidos.

**Importante:** este repositório é separado do sistema privado LanchesPrime. Alterações ou dados deste projeto demonstrativo não interferem no projeto original.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/LanchesPrime-demo.git
```

### 2. Entre na pasta

```bash
cd LanchesPrime-demo
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```
