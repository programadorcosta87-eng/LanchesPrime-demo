# LanchesPrime — demonstração pública

Versão demonstrativa e independente da interface do LanchesPrime, criada para apresentação de portfólio.

> **Aviso:** este é um projeto de demonstração. Os produtos, descrições e preços são ilustrativos. Não aceita pedidos reais, não possui login, painel administrativo, banco de dados, APIs privadas ou integração com pagamentos.

## O que esta versão demonstra

- Página inicial, identidade visual e navegação responsiva.
- Seção institucional e cardápio com filtros por categoria.
- Interação local de demonstração para adicionar itens (sem enviar ou armazenar pedidos).
- Layout adaptado para celular e desktop.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS

## Executar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Privacidade e segurança

Este repositório foi preparado como vitrine pública. Não inclua aqui credenciais, arquivos `.env`, dados de clientes, pedidos reais, dumps de banco de dados, chaves, tokens ou código de serviços privados. A interação do cardápio ocorre apenas no navegador e é reiniciada ao recarregar a página.

## Observação sobre imagens

As imagens do cardápio são carregadas de URLs públicas do Unsplash. A disponibilidade dessas imagens depende do serviço externo.

---
Projeto demonstrativo — não representa um serviço de pedidos em produção.
